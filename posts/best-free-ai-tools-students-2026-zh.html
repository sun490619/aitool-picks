1. NotebookLM——最佳调研笔记

NotebookLM 把 PDF 和网页变成音频摘要和学习指南。上传你的教材章节，就能得到一段可以在通勤路上听的播客式总结。

2. Quizlet AI——最佳闪卡

Quizlet 的 AI 功能从你的笔记自动生成闪卡。"Magic Notes"几秒就把凌乱的大纲转成干净的问答卡。

3. GitHub Copilot（免费）——最佳 CS 学生之选

GitHub Copilot 现在通过 GitHub Student Developer Pack 对所有学生免费。VS Code 里实时代码建议，外加 Copilot Chat 调试。

4. Perplexity AI——最佳论文调研

Perplexity 把 AI 搜索和来源引用结合。做文献综述极佳——你拿到的是带可点击参考文献的答案，不是一堵文字墙。

5. Grammarly（免费）——最佳论文写作

Grammarly 免费档抓语法错并建议清晰度改进。对多数学生论文够用；只有需要高级风格检查才升级。

6. Notion（免费）——最佳笔记整理

Notion 免费方案对学生很慷慨。建个人 wiki、跟踪作业、协作小组项目——全在一个工作区。

7. Canva（免费）——最佳演示文稿

Canva 的 AI Magic Design 把文字提示变成幻灯片。适合设计不是重点的课堂快闪演示。

8. Wolfram Alpha（免费档）——最佳 STEM

Wolfram Alpha 算数学、画图表、一步步解物理题。免费档能应付多数作业任务。
