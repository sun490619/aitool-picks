我们实测的关键功能

1. 懂代码库的自动补全

Cursor 首次打开就索引整个仓库。自动补全（Tab）引用的是跨项目的文件，不只是当前打开的。在 Next.js 测试里，它正确地从我们这轮从没打开过的兄弟文件里导入工具函数。

Copilot 读当前文件、也许还有几个邻居；Cursor 读的是整个仓库。

2. Cmd+K 行内编辑

选中代码，按 Cmd+K，打一句自然语言改动。它就地编辑，并行内显示 diff。无需 Chat 面板。对重构和修 bug，这比复制粘贴进 ChatGPT 更快。

3. 带代码库上下文的 Chat

Chat 面板索引整个仓库。像"用户鉴权中间件定义在哪"这样的查询，返回精确文件路径带片段预览。测试中，它找逻辑比 ripgrep + grep 还快。

一个限制：免费方案只索引你打开过的文件。Pro/Business 在首次加载时预索引整个仓库。

4. 多文件编辑（Agent 模式）

Agent 模式能在一个请求里改多个文件。我们测了"给所有路由组件加错误边界"——它改了应用里 6 个文件、更新了错误 UI、还加了测试。手动做要 15–20 分钟。
