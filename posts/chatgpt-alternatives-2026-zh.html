为什么要找替代品

你想换工具，通常是为了更低的价格、更长的上下文窗口、更强的隐私，或是一款专做某件事、而非通用助理的工具。

最佳替代品

Claude (Anthropic) — 细腻写作最强

Claude 是 ChatGPT 在严谨长文写作上最接近的对手。它 20 万 token 的上下文窗口让你能把一整篇论文或书稿贴进去，要求它做编辑、摘要或保持你语气的改写。它的长处在于判断力：会质疑薄弱的前提、标出站不住的论断，处理敏感话题时带护栏而非直接拒绝。如果你对 ChatGPT 的不满是"它太顺着我说"，Claude 就是解药。

Gemini — Google Workspace 内最强

Gemini 真正的优势在于它"住在哪里"。因为它原生集成在 Google Workspace 里，你可以用大白话让它总结一个 Drive 文件夹、在 Gmail 里起草回复，或把一张 Sheets 表格变成图表。它的多模态输入（图片、PDF、视频）对学生和分析师很有用。如果你的工作本来就活在 Google 生态里，它是很强默认项，只是免费档的限速比 ChatGPT 更紧。

Perplexity — 带引用的研究最强

Perplexity 颠覆了聊天机器人模式：它不靠可能编造事实的对话，而是给出可点击核实的链接来源。对于"数据说了什么""总结这家公司"这类任务，那条引用链才是重点。它不是好的创意写手，但要做快速、有出处的研究，它能替你省下十几趟搜索标签页。Pro 档在底层叠加了 GPT-4 级别和 Claude 模型。

GitHub Copilot — 编辑器内写代码最强

Copilot 待在你的 IDE 里，所以这里取代 ChatGPT 的是"上下文"而非聊天。它边打字边建议整段函数、把注释变成可运行代码、解释你接手的旧代码块。对觉得 ChatGPT 复制粘贴写代码太慢的工程师，Copilot 省掉了切标签页的麻烦。它现在还能处理终端命令和 PR 摘要。

Microsoft Copilot — Office 365 内最强

如果你的整天是 Word、Excel、PowerPoint，就选 Microsoft Copilot。它能用一份文档生成整套幻灯片、清理乱糟糟的 Excel 表格、用你的公司口吻重写备忘录。它不像 ChatGPT 那样是通用聊天机器人，但对那些本来就不想要聊天机器人的办公族来说，这种"窄"恰恰是重点。

怎么选

按主要用途选：写作与安全 → Claude；Google Workspace → Gemini；带引用的研究 → Perplexity；写代码 → GitHub Copilot 或 Claude；出图 → Midjourney 或 DALL·E。

常见问题

最好的免费 ChatGPT 替代品是什么？

Claude（免费档）、Perplexity 和 Meta AI 都有能用的免费档。Claude 写作质量领先，Perplexity 擅长带引用的研究。

哪个 ChatGPT 替代品最适合写作？

Claude 普遍认为最强于长文、细腻写作，且能紧密遵循安全与风格指令。

哪个最适合编程？

编辑器内补全用 GitHub Copilot；较大规模重构用 Claude 或 Cursor。

怎么按需求挑替代品

选 ChatGPT 替代品的第一步，不是看"哪个最强"，而是看"你最常在哪个场景卡住"。如果你 80% 的需求是写作、改文案、润色邮件，Claude 的细腻程度往往比 ChatGPT 更对你胃口，尤其在需要克制语气、保持人味的长文上。如果你整天泡在 Google 文档、表格、邮箱里，Gemini 因为原生嵌在 Workspace 里，随手就能在正在写的东西旁边调出来，这种"不用切换"的顺滑感是独立工具给不了的。做研究、需要每句话都带引用来源的人，Perplexity 几乎是为这个场景生的。写代码且不想离开编辑器，GitHub Copilot 直接在你敲字的地方补全，比开个网页对话再复制回来快得多。Microsoft Copilot 则适合已经被 Office 365 绑定的职场人。所以挑法很简单：先列你最高频的三件事，再去找那三件事里最顺手的那一个，而不是追一个"全能冠军"——全能往往意味着在你最常用的那件事上不够尖。

免费版够用吗：各家免费额度真相

几乎所有替代品都把"免费"当成引流钩子，但免费的含义天差地别。Claude 的免费档能聊，但高级模型和高频使用会被限速，重度用户很快感到被掐着脖子。Gemini 的免费档相当大方，尤其和 Google 账号绑定时几乎无感。Perplexity 免费版能用，但每天 Pro 搜索次数有限、可选模型受限，研究量一大就撞墙。Copilot 在编辑器里的免费档是真实可用的，只是会限流。关键认知：免费档的设计目标是"让你尝到甜头然后想升"，所以轻度用户（每天几条对话、偶尔查资料）完全够；但如果你每天靠它干活、靠它交付，免费档的限速和模型降级会在你最忙的那天准时出现。建议：先用免费档跑两周，记下自己被卡了几次，再决定要不要为那几次卡顿付月费——别一上来就买，也别等 deadline 当天才发现免费档救不了你。

隐私与数据：哪些不会拿你的对话训练

这是多数人挑工具时忽略、出事时才后悔的维度。把客户资料、公司内部文档、甚至自己的日记丢进一个会拿对话去训练模型的免费工具，等于把机密公开给下一代模型。各家政策不同：Claude 在付费档明确承诺不拿你的对话训练；ChatGPT 的付费档同样有不用于训练的选项（需在设置里关掉）；Perplexity 在研究场景强调引用但不等于免责；而一些小而美的工具，免费档默认就可能用你的输入优化模型。实操建议：① 任何含敏感信息的活，只用明确"不训练"的付费档；② 永远别在对话里贴密码、API key、真实身份证号；③ 把"这个工具会拿我的数据干嘛"当成和"它好不好用"同等重要的决策项。工具再强，把你自己的机密喂进去都是得不偿失——隐私这条线，宁可贵一点、保守一点。

组合使用比单挑一个更划算

成熟用户几乎不会只守一个工具，而是把替代品当"工具箱"用。一个高效组合：日常写作和长文用 Claude，研究查证用 Perplexity（每句带引用），代码补全用 GitHub Copilot，Google 生态内随手问用 Gemini，正式邮件和文档润色再回到 Claude。这样你每个场景都用了"最顺手的那把刀"，而不是拿一把瑞士军刀去砍所有的活。成本上也不贵——多数人的真实用量，一两个付费档就覆盖了，剩下用免费档补齐。比"死忠某一个品牌、为它的短板硬扛"划算太多。记住：替代品存在的意义不是"取代 ChatGPT"，而是让你在 ChatGPT 不擅长的那块，有更尖的选择。会搭配的人，单位时间产出明显更高，也更不容易被单一工具的限速和涨价拿捏。

API 调用成本与速率限制：按 token 单价选型最省钱

多数替代品的免费额度只够写短文。以 Claude 3.5 Sonnet 为例，输入 3 美元/百万 token、输出 15 美元/百万 token，而 Gemini 1.5 Pro 输入 1.25 美元、输出 5 美元。若每天生成 50 篇 800 字博客，Claude 每月成本约 72 美元，Gemini 仅 28 美元。

速率限制常被忽略：ChatGPT 免费版每 3 小时 40 次，而 Claude 免费版是每 5 分钟 20 次。批量改写 100 条商品描述时，用 Gemini API 的 RPM 限制（每分钟 60 次）比网页端手动复制快 3 倍。建议用 OpenRouter 聚合接口统一调度，避免单一平台限流。

常见误区：只看输出单价，忽略输入 token 重复消耗。长文润色时，输入占 70% 成本。实测用 Mistral Large 处理 5000 字稿件，输入 token 费用占 82%。选型前用 tokenizer 工具（如 tiktoken）统计真实消耗，再对比性价比，而不是盲目追新模型。
